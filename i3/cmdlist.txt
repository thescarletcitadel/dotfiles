cd = change directories
touch = create empty file
rm = remove file or directory
mkdir = make new directory
ls = list files
la = ls -a shows the hidden files inside of the directory
cp = copy file recommend using -r to recursively copy files
mv = move or rename file
cat = view file content
grep = search text in files
chmod = change file permissions
chown = change file owner
curl = get info from website (sometimes download imgs)
nano = open nano text editor
nvim = open neovim text editor
sudo = execute command as root
history = show command history
ps = show running processes
pkill = terminate process
killall = kills everything with the matching name
ssh = connect to remote server
scp = allows copying to remote servers
ping = test network connectivity
man = typing man will show the manual of a command
fstrim -av = this will remove unused sectors of ssd
shred -uzv -n 3 [file] = shreds the data of a file run before fstrim
